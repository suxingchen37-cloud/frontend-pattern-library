# 前端模式库

一套可直接点、可直接复制的通用前端参考库：144 个真交互效果、设计系统、内容呈现规范，外加一个完整示范站《缓坡》。纯静态、零依赖、单页入口。

## 运行

```bash
node serve.mjs
# http://127.0.0.1:8801/
```

端口可用 `PORT=8802 node serve.mjs` 覆盖。

## 结构

| 标签 | 文件 | 内容 |
|---|---|---|
| 动效与交互 | `motion-lab.html` + `lab-more.js` + `lab-extra2.js` + `lab-extra3.js` | 144 个真交互效果，22 个分类；点「选中」→「复制清单」取 id |
| 设计系统 | `design-system.html#design` + `ds-specs.js` | 颜色令牌、7 档字阶、间距/圆角/阴影、24 个可复制图标、空态插画、组件六态矩阵；另加 50 条组件/状态图鉴（活体示例 + 规则 + 反例） |
| 内容呈现 | `design-system.html#content` + `ds-content.js` | Markdown、代码块（行号/高亮/复制）、diff、图片查看器、文案语气；另加 50 条内容小样（文本/数据/媒体/引用/长文/代码/交互/结构） |
| 整站实战 | `site/` | 虚构独立刊物《缓坡》：首页 / 文章 / 往期 / 关于，编辑版式、长文、筛选、表单与明暗主题 |

`index.html` 是唯一入口与标签外壳；页面选择存 `localStorage`，夜间主题通过 `?theme=` 与 `postMessage` 同步进内容页与示范站。

## 宽屏与交互

- **≥1600px**：动效页三栏（左分类栏 / 中流式网格 / 右已选面板）；设计系统与内容呈现为左分组栏 + 流式图鉴；首页 4 张开入口卡铺开。
- **1200–1599px**：动效页与图鉴保留左栏，已选收进右下浮动胶囊。
- **<1200px**：左栏收起，分类回到单行横滑；<640px 网格单列。
- 动效页记住筛选、搜索、滚动位置、密度；图鉴记住分组、搜索、密度和页面滚动位置。
- 选中后可从右侧面板或浮动胶囊里回看、定位、移除；支持「只看已选」「复制清单」。
- 每张卡支持复制 CSS、复制整卡（HTML + CSS）、全屏预览；预览里可复制深链接（`?tab=motion&demo=id`）。
- 键盘：`/` 聚焦搜索，`Esc` 清空搜索 / 关闭预览。
- 动效与图鉴按分类懒渲染（首屏只画视口附近的分类），长列表不一次性构建。

## 示范站《缓坡》

- `site/index.html`：封面、本期文章、编辑室手记、订阅表单
- `site/article.html`：长文排版，阅读进度、目录跟随、脚注浮层、复制链接
- `site/archive.html`：12 篇文章，栏目筛选、搜索、列表/网格切换、空结果
- `site/about.html`：编辑室、撰稿人、投稿步骤、联系表单（前端校验）

全部为静态演示，不连接后端；表单只做本地校验与反馈。

## 设计图鉴 / 内容图鉴

`ds-specs.js`（50 条规格）和 `ds-content.js`（50 条内容小样）用同一套条目结构：`{ id, group, t, en, rule, dont?, body, css, init? }`；`ds-render.js` 负责按分组筛选、搜索、作用域化 CSS 和挂载交互。新增一条图鉴只需往对应数组里追加条目，不用改页面结构。

## 加一个效果

1. 在 `lab-more.js`、`lab-extra2.js` 或 `lab-extra3.js` 的 `window.DEMOS_EXTRA` 里追加 `{ id, cat, t, en, d, body, css }`。
2. 需要交互时，在 `window.INITS_EXTRA` 里挂同名初始化函数。
3. 每张卡的 CSS 会被 `scopedCss()` 按卡片 id 作用域化；卡内布局注意 `min-width: 0`，避免撑破网格。

加载顺序的两个约束：`DEMOS.push(...DEMOS_EXTRA)` 必须在分类计算之前；`Object.assign(INITS, INITS_EXTRA)` 必须在 `INITS` 定义之后。
