# 排版判断手册（不预设风格）

排版服务于当前内容和用户任务。本文件不规定配色、字体、字阶数量、固定栅格、统一行宽或必须出现的视觉记忆点。
`agent/layouts/` 提供可修改的结构示例，尺寸和表现只作示意；可以选择、组合，也可以完全不用。

## 先判断内容

- 明确用户先看什么、接着比较什么、最后做什么；按这条阅读和操作路径安排区块。
- 长文、表格、图像与操作控件需要不同的空间，不要把所有内容塞进相同卡片。
- 用真实标题、长文案、数字和空状态验证布局，避免占位内容造成的假整齐。

## 层级与阅读

- 通过位置、字号、字重、行距与留白建立清晰主次，避免所有元素都像标题。
- 行宽与行距随语言、字号、内容密度和屏幕调整，以连续阅读不丢行为判断依据。
- 字体选择服从内容与品牌，检查中文、数字及缺字回退；不要求固定字族或混搭字体。
- 对齐应表达关系；同组元素有共同基准，特殊对齐应有内容或操作上的理由。

## 密度与分组

- 组内距离表达联系，组间距离表达边界；留白按信息关系决定，不机械等分。
- 数据比较时保持单位、数字精度与对齐一致；正文与操作控件不必使用相同密度。
- 容器、描边、阴影和颜色都是可选的分组手段，选择适合当前任务的方式。

## 避免 AI 模板感

- 不把“首屏＋三张卖点卡＋功能网格＋口号”当所有页面的默认顺序。
- 不为了看起来丰富而增加大数字、装饰标签、无关图标或重复说明。
- 不要求每页刻意破格；稳定的信息结构、系列一致性与安静的布局也可以是正确选择。
- 页面差异来自内容与任务，不通过更换颜色、凑骨架或强制两项不同来伪造变化。

## 交付前检查

- [ ] 真实内容的阅读顺序和操作优先级清楚。
- [ ] 内容分组有依据，没有机械堆砌容器或重复区块。
- [ ] 目标屏宽、长内容、缩放与键盘操作下仍可使用。
- [ ] 字体回退、对比度、焦点与必要交互状态已检查。
- [ ] 能说明关键布局选择与未验证项，无需套固定风格或刻意破格。
