# 不对称双栏（asymmetric-two-col）

> 可修改的局部结构参考；不是整页模板，也不是必须选择的有限列表。尺寸、字体和动效不约束消费方风格。

- 栅格：用不等宽的两列区分索引与主体，比例由两侧内容决定；是否粘性定位按导航需要选择。
- 行宽/字号：检查索引长度、正文行宽与窄屏换行，字体和字号按项目决定。
- 层级：根据索引与内容的实际关系建立主次，不限定层级数量。
- 留白节奏：用间距表达条目内与条目间的关系，尺寸由内容密度决定。
- 可选内容关系（按需求取舍、重排，不是页面顺序）：可选的索引或导航；按实际内容生成主体条目；任务需要的后续操作
- 动效性格：可无动效；需要反馈或定位时按关系选择合适的动效。
- 别这么干：避免窄列裁切必要内容，窄屏时可改为单栏；等宽布局在适合时也可使用。
