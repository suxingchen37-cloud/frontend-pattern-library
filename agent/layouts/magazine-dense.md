# 杂志密排（magazine-dense）

> 可修改的结构示例；尺寸、字体和动效均为示意，不约束消费方的视觉风格。

- 栅格：信息丰富时可采用多栏或混合布局，栏数、对齐和跨栏由内容决定，不要求刻意错位。
- 行宽/字号：栏宽、字体与行距按语言和内容密度检验，窄屏保持正确阅读顺序。
- 层级：标题、栏目、正文、图注和边注按实际编辑内容组织。
- 留白节奏：在信息密度与可扫描性之间调节，不设必须留空或刻意破格的区域。
- 典型区块顺序：必要的刊头或主题入口 → 按真实篇目组织的内容 → 有信息价值的图像与注释（按需）
- 动效性格：阅读与定位需要时再添加动效，也可保持静态。
- 别这么干：避免为了模拟杂志而制造拥挤或打乱阅读路径。
