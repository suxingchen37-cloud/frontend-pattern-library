# 目录索引（directory-index）

> 可修改的局部结构参考；不是整页模板，也不是必须选择的有限列表。尺寸、字体和动效不约束消费方风格。

- 栅格：可用行式、分组或其他适合的索引结构，字段位置由查找任务决定。
- 行宽/字号：标题与说明在目标屏宽可读，长内容允许换行或提供完整查看。
- 层级：索引名、说明、分类与数量按实际信息选用，不要求固定组合。
- 留白节奏：条目间距与分隔方式按分组和扫描任务决定。
- 可选内容关系（按需求取舍、重排，不是页面顺序）：说明索引用途的入口；按真实条目数量组织的目录；需要时提供搜索、筛选或后续操作
- 动效性格：根据选中、展开或结果更新提供必要反馈，也可无动效。
- 别这么干：避免为了统一条目长度删掉关键信息；卡片、居中或行式布局均可按任务使用。
