# 仪表盘栅格（dashboard-grid）

> 可修改的局部结构参考；不是整页模板，也不是必须选择的有限列表。尺寸、字体和动效不约束消费方风格。

- 栅格：指标、图表与明细按分析任务分区，不限定列数、跨列数或卡片数量。
- 行宽/字号：数字、单位和标签清楚对应；对齐、字体与字号按比较需要决定。
- 层级：先明确要回答的问题，再决定指标、解释、图表和明细的主次。
- 留白节奏：按比较关系与操作密度分配空间，阴影、描边、留白等可按项目需要选择。
- 可选内容关系（按需求取舍、重排，不是页面顺序）：有真实来源的指标（按需）；服务分析任务的图表（按需）；可追溯的明细（按需）；必要的空结果、等待和失败状态
- 动效性格：按真实状态和数据关系选择反馈，可不用动画。
- 别这么干：不为填满栅格虚构指标或重复卡片；装饰和渐变等元素按内容需要判断。
