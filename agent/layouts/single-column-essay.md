# 单栏长文（single-column-essay）

> 可修改的结构示例；尺寸、字体和动效均为示意，不约束消费方的视觉风格。

- 栅格：连续阅读可采用单栏，宽度、对齐与注释位置由语言、字号和设备决定。
- 行宽/字号：用真实长文检查行宽、换行与注释阅读，不限定字符数或字号。
- 层级：标题、小节、正文、导语与注释按实际内容组织，不要求固定层级。
- 留白节奏：按段落关系、章节节奏与屏幕空间分配留白。
- 典型区块顺序：必要的标题与内容说明 → 按真实语义分段的正文 → 有助理解的引用、图像或注释（按需）
- 动效性格：连续阅读无需默认入场动画；需要状态或定位反馈时再添加。
- 别这么干：避免机械添加小标题或容器；确需分组、比较或操作的内容可用卡片等结构。
