# 排版手册（跨风格通用）

好看不是"加装饰"，是**尺度、对齐、留白**三件事做到位。下面是可执行的判据，不是形容词。

## 一、先定测量线，再放东西

- **行宽**：正文 60–75 个字符（中文 28–40 字）。超过 80 字符，眼睛会丢行。
- **一条主线**：全页左对齐（或全页居中，二选一）。居中只用于短块：标题、数字、单一 CTA。
- **栅格**：要么 12 列（可 2/3/4/6 分），要么单栏定宽。**不要既用栅格又用魔法边距。**

## 二、尺度要拉开，不要挤

- 层级**最多 4 层**：大标题 / 小节 / 正文 / 注释。
- 相邻字号至少差 **1.25 倍**；重要反差直接拉到 **2–3 倍**（例：96 / 34 / 15 / 11）。
- **禁止** 13/14/15 这种挤在一起的伪层级——那不是层级，是犹豫。
- 标题字距收紧 **-2%~-4%**；正文 0；小号等宽标签 **+6%~+8%**。
- 行高与字号成反比：大标题 1.0–1.1，正文 1.6–1.8，注释 1.5–1.6。

## 三、留白要有节奏，不能均匀

- 只用一个**间距基数**（4 或 8），取 1/2/3/5/8 倍。
- **段间距 ≠ 行距**：段间距通常是行距的 1.5–2 倍，否则读起来是一大坨。
- 均匀留白最显平庸。至少做一次**密度对比**：一段密排（表格、注释）+ 一块大留白（标题周围）。
- 区块之间的关系用留白表达，不要每块都加边框。

## 四、对齐与视觉重量

- 视觉重量靠**面积**：一张满宽图 > 一个标题 > 一段文字。别让次要元素抢面积。
- 数字、表格用等宽并右对齐；只有两行数据时不加表头。
- 图标与文字基线对齐，别让图标把行距撑高。
- **刻意破格只允许一处**：一条线溢出容器、卡片错位半格、标题压上图片一角。第二处就等于没有基准。

## 五、怎么做到"不重复"

同一个库要做出不同的页面，靠的是**换骨架**，不是换颜色：

1. **先选版式骨架**（见 `agent/layouts/`）：单栏长文 / 不对称双栏 / 满幅主图 / 目录索引 / 仪表盘栅格 / 杂志密排。
2. **再选风格**（六色位 + 两个字族 + 取向）。
3. **最后定记忆点**：这一页只有哪一处是别人不会做的？
4. 交付说明里必须写清这三件：**骨架 / 风格 / 破格**。写不出来，说明你在套模板。

判断有没有重复：把这一页的骨架名、色位、记忆点，和上一次做的页面并排比。**三样里至少两样不同**，否则算重复。

## 六、交付前排版自检

- [ ] 正文行宽 60–75 字符（中文 28–40 字）
- [ ] 层级 ≤4 层，相邻字号差 ≥1.25 倍
- [ ] 只用了一个间距基数，且有密度对比
- [ ] 段间距 ≠ 行距
- [ ] 全页一条对齐主线；居中只用于短块
- [ ] 破格只有一处
- [ ] 交付说明写了骨架 / 风格 / 破格
